# 0003 奖牌分享图

日期：2026-10-24 · 状态：已采纳

## 决定

奖牌详情的工具栏增加「分享」按钮，只对已获得的奖牌显示；未获得的奖牌和 Debug 预览状态下都不显示。

点击后弹出预览，下方提供两个按钮：

- **复制图片**：写入剪贴板（PNG）。浏览器不支持写入图片时，按钮置灰，并说明原因。
- **下载图片**：保存为 PNG 文件，文件名形如 `dsh-medal-星河万里-000049.png`。

### 图片内容

1080×1350（4:5 竖版），深色展台背景，从上到下依次是：

1. 奖牌：固定展示角度（正面略微斜侧），单独高分辨率渲染，不受详情里当前旋转角度影响。
2. 系列与档次，例如「探索里程碑 · 珍藏」。
3. 奖牌名称。
4. 挑战条件。
5. 当前选中的那条获得记录：获得日期和序号；以及获得次数，例如「第 10 次获得」。
6. 截至分享当天的累计用量，例如「截至 2026-10-24 累计 1.44B tokens」。
7. 底部 DSH MEDALS 标记。

文字跟随当前界面语言。

## 影响

- 分享图会公开个人累计用量。这是用户主动选择的结果；分享前可以先看到预览。
- 无法使用 WebGL 时，分享图改用预先渲染的正面图片。
- 奖牌馆运行在 DSH 的 iframe 中，复制图片需要宿主为 iframe 授予 `clipboard-write` 权限。
