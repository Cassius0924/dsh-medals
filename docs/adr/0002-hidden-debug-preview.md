# 0002 隐藏 Debug 预览入口

日期：2026-10-24 · 状态：已采纳

## 背景

Debug 预览是开发和设计检查用的工具，普通用户用不到。之前它先放在页面右上角，后来挪到页脚右下角，仍然对所有用户可见。

## 决定

- 移除页脚的「Debug 预览」按钮。
- 连续点击「奖牌馆」标题 5 次开关 Debug 预览；相邻两次点击间隔超过 2 秒就重新计数。
- 每次开关都在底部弹出提示「Debug 预览已开启」或「Debug 预览已关闭」。
- 进入 Debug 预览后，页面顶部仍然显示原有的 Debug 工具栏，可以切换「全部已获得 / 全部未获得」。

## 影响

- Debug 预览只能用鼠标或触摸打开，键盘无法触发。它属于开发工具，这样处理可以接受。
- 自动化测试改为连点标题 5 次进入 Debug 预览。
