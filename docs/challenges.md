# 挑战与收藏

固定日用量门槛与绝对用量里程碑并行；日常同款计次数，周期保留日期版。持续达标为主线，用量与增长为支线。

每日达到 5M tokens 计作一个达标日；单日 5M、10M、20M 对应三档每日奖牌。门槛对所有用户一致。

| 系列 | 档位 | 收藏方式 |
|---|---|---|
| 日常 | 单日 5M、10M、20M tokens | 每日每档一次，同款计数 |
| 周常 | 一周达标 3 天、5 天、完整 7 天 | 每周每档一次 |
| 月度 | 一月达标 10 天、20 天、完整全月 | 每月每档一次 |
| 达标日里程碑 | 累计 7、30、100、365 天 | 每档一次，不要求连续 |
| 用量里程碑 | 累计 100M、500M、1B、5B、10B | 每档一次，历史补发 |
| 周期用量 | 周 50M、月 200M | 每期一次，历史补发 |
| 增长突破 | 周增长 100%（前周≥5M）、月增长 200%（前月≥20M） | 完整周期结束结算，历史补发 |

共 22 项挑战，不把重复获得或日期版算作新的挑战款。普通挑战结构克制且以数字为主体；进阶增加几何层次；长期、完整月与高档里程碑使用精工收藏等级。

日常、周常、月度 10/20 天与累计 7/30 天使用数字造型。六款具象精工主题对应当前挑战：周 50M「恒星轨道」、月 200M「月面漫游」、周增长 100%「向上生长」、月增长 200%「破晓之势」、累计 100M「里程初章」、累计 500M「无尽远行」。更高的用量与达标日里程碑、完美一月也使用雕塑造型版本。合计 10 项数字款、12 项雕塑款；12 项雕塑挑战各有独立主题：常青之树、罗盘、珍珠花章、里程层阶、无尽环、棱晶、星座、星河、恒星轨道、月相、上升折面与破晓。

达标日从启用挑战的当天开始累计。首个不完整周期可参与够得着的天数档；完美周/月必须完整观察整个周期，且结束后授予。历史绝对用量与增长正常回算。首次回算安静补发，所有挑战与获得记录统一展示在收藏馆。

每个新奖牌保留类型、日期周期、获得日、序号、当次目标/用量与已读状态。已得记录不随源日志删除而撤销。任何暂时读取失败暂停新授奖；DSH 明确拒绝解析的格式透明排除。

未解锁显示外形、主体特征线与进度，可以打开挑战说明但不能查看完整 3D 或背面。获得后揭晓完整奖牌，开放鼠标、触摸和键盘旋转。

Debug 样式预览可一键将全部奖牌切换为已获得或未获得外观。预览明确标识，不写入真实记录，不能确认授奖；退出或刷新恢复真实状态。
