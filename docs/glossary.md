# 术语表

界面文案和代码注释统一使用以下说法。

| 术语 | 含义 | 不要用 |
| --- | --- | --- |
| 奖牌 | 收藏中的一个品类，对应一项挑战，例如「单日 5M」「星河万里」。代码中称为 rule。 | 徽章、成就 |
| 挑战 | 获得某枚奖牌的条件。 | 任务 |
| 获得记录 | 某枚奖牌的一次获得，带日期周期、获得日和六位序号。同一枚奖牌可以有多条，代码中称为 award。 | 奖励、实例 |
| 达标日 | 单日用量达到 5M tokens 的自然日。 | 打卡日 |
| 数字奖牌 | 以凸起数字为主体的珐琅圆章，用于日常和早期持续挑战。 | 普通奖牌 |
| 造型奖牌 | 有独立主题造型的奖牌，例如恒星轨道、常青之树、星河万里。 | 特殊奖牌 |
| 收藏馆 | 奖牌馆的主页，按系列分组陈列全部奖牌。 | 图鉴 |
| 展台 | 收藏馆顶部的深色区域，轮流展示已获得的奖牌。代码中称为 hero。 | 横幅 |
| 揭晓 | 新奖牌的获得动画。看完后该条获得记录记为已读。 | 庆祝、弹窗 |
| 已读 | 获得记录已经在揭晓中展示过。首次同步补发的记录直接记为已读。 | 已确认 |
| 补发 | 首次同步时按历史用量颁发的获得记录，不播放揭晓。 | 回填 |
| 分享图 | 从奖牌详情生成的 4:5 竖版图片，可以复制或下载。 | 海报 |
| Debug 预览 | 只改变外观、不写入记录的样式预览。连点 5 次「奖牌馆」标题开关。 | 测试模式 |

## 探索里程碑系列

用量累计系列共五档，从 100M 到 10B：

| 档位 | 名称 | 英文名 | 造型 |
| --- | --- | --- | --- |
| 100M | 里程初章 | First Milestone | 层叠金属方阶 |
| 500M | 无尽远行 | Endless Voyage | 立体无尽环 |
| 1B | 星火初燃 | Starfire | 圆形珠边外框，放射光芒托起切面星核 |
| 5B | 群星为图 | Star Chart | 八角星形外框，带刻度环的星图盘 |
| 10B | 星河万里 | River of Stars | 双层外框加十二道放射尖角，多层珐琅旋臂星系 |

1B、5B、10B 的设计决定见 [ADR 0001](adr/0001-cosmic-milestones.md)。

## 每月用量系列

自然月用量累计，每个自然月每档可获得一次。造型为写实立体天体，每档带前一档天体作伴星，与抽象纹样的探索里程碑系列区分。

| 档位 | 名称 | 英文名 | 造型 |
| --- | --- | --- | --- |
| 200M | 月面漫游 | Lunar Journey | 月球：月海、环形山与辐射纹 |
| 500M | 蔚蓝家园 | Blue Home | 地球，伴月球 |
| 1B | 日冕之光 | Solar Corona | 太阳，日冕光晕与日珥，伴地球 |
| 3B | 事件视界 | Event Horizon | 黑洞，吸积盘与透镜光弧，伴一颗被吸入的恒星 |
